# 7. Игра встраивается в монорепозиторий TRGames

Дата: 2026-09-21

## Статус

Принято

## Контекст

У заказчика есть работающий проект TRGames (github.com/TroExol/trgames) —
настольные игры в браузере для игры с друзьями, React 18, TypeScript, MobX,
Socket.io, Vite, развёрнутый на toexol.ru. В нём одна игра, Cryptoz.

Монорепозиторий изначально размечен под несколько игр: `server/src/games/`,
`client/src/routes/games/`, `tools/shared/src/games/`.

В нём уже есть почти всё, что мы собирались писать заново:

- общая инфраструктура в `server/src/helpers` — SocketGroup, Logger,
  Modifiers, Triggers, FunctionResultObserver;
- `connectionStateRecovery` с окном 30 секунд — буквально наша политика для
  отвалившегося игрока;
- `emitWithAck` в SocketsService — сервер задаёт вопрос конкретному игроку,
  ждёт ответ, держит очередь неотвеченных, отваливается по таймауту. Это
  механика нашего «Выбора» и выбора цели эффекта;
- диалоги на клиенте: DialogService, DialogStore, CollapsibleDialog с
  правилом «одна активная модалка плюс одна свёрнутая»;
- Tailwind с CSS-переменными, next-themes, framer-motion — сгенерированная
  палитра подключается без новых зависимостей, движение фишек тоже;
- настроенные сборка, линтинг, тесты и деплой.

## Решение

Бродилка добавляется в TRGames второй игрой, а не создаётся отдельным
проектом.

PostHog в новой игре не используется: он недоступен в России. Учёт расхода
токенов (шов 2 из ADR-0005) ведётся в собственной таблице. Выпиливание
PostHog из Cryptoz — отдельная задача, в объём этой работы не входит.

## Последствия

Отдельный проект означал бы заново написать комнаты, сокеты, диалоги, выбор
цели, сборку, линтинг и деплой — всё уже отлаженное.

Цена: платформенный слой пока декларативен. Room, RoomGroup и SocketsService
лежат внутри `games/cryptoz`, а не в общем слое. Вторая игра заставит вынести
общее наружу, и это настоящая работа, а не пара импортов. Зато после неё
TRGames становится платформой по факту, а не по структуре папок.

Стек наследуется целиком, включая решения, которые мы иначе приняли бы иначе:
Yarn вместо npm, React 18, MobX. Пересматривать их ради одной игры смысла нет.

Наблюдение, подтверждающее ADR-0003: в Cryptoz карта — это класс на
TypeScript, отдельный файл со своим тестом, и нейросеть участвует в её
создании на этапе разработки. У нас карта генерируется в рантайме, а значит
обязана быть данными, а не кодом. Композиция из атомов — это и есть то, что
делает генерацию в рантайме возможной.
