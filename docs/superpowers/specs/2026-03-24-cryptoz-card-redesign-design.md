# Редизайн карточек Cryptoz

Новый дизайн карточек в стиле Premium Glass: чистый, минималистичный dark fantasy с акцентом на арте и иконографии.

## Решения

| Аспект | Решение |
|--------|---------|
| Визуальный стиль | Premium Glass — полупрозрачный фон, мягкие тени, backdrop-blur |
| Приоритет информации | Арт + название — главный акцент |
| Статы (эссенция, урон) | Убраны как отдельные элементы, читаются из описания через иконки |
| Таргет карты | Убран с карты |
| Дифференциация типов | Тонкий цветной бордер + lucide-иконка типа |
| Текст механик | Убран ("Мракобой", "Укрытие" и т.д.), заменён на lucide-иконки |

## LG карта (240×370) — модалка

### Структура (сверху вниз)

1. **Арт** (~45% высоты, ~150px)
   - Градиентный fade снизу в фон карты
   - Поверх арта (absolute, верх-лево): стоимость (зелёный орб) + осколки славы (янтарный бейдж со звездой)
   - Поверх арта (absolute, верх-право): тип карты — glass-бейдж с lucide-иконкой + текст названия типа

2. **Название** (отдельная строка под артом)
   - font-size: 15px, font-weight: 800
   - Тонкий разделитель снизу (1px, цвет типа с низкой прозрачностью)

3. **Описание** (flex: 1, заполняет оставшееся пространство)
   - Центрировано по вертикали и горизонтали (flexbox, justify-content: center, align-items: center, text-align: center)
   - Без буллитов
   - Иконки inline из lucide вместо текста механик
   - Каждое свойство (general, strike, evade, totalStrike, seal, other) — отдельная строка
   - Названия механик заменены на иконки: sword → мракобой, shield → укрытие, crosshair → тотальный мракобой, sparkle → печать
   - Свойство `other` отображается как обычный текст без специальной иконки
   - Свойство `general` не имеет иконки-префикса механики
   - При переполнении текста описания используется auto-fit размер шрифта (min 9px)

### Элементы поверх арта

**Стоимость (верх-лево):**
- Круглый орб, 24×24px, border-radius: 50%
- Фон: radial-gradient (#065f46 → #022c22)
- Бордер: 1.5px solid rgba(16,185,129,0.35)
- Тень: box-shadow 0 0 8px rgba(16,185,129,0.2)
- Текст: белый, 11px, weight 800

**Осколки славы (справа от стоимости):**
- Бейдж с lucide star иконкой + число
- Фон: rgba(66,32,6,0.7) с backdrop-filter: blur(4px)
- Текст: #fbbf24, 10px, weight 700
- border-radius: 8px, бордер: 1px solid rgba(146,64,14,0.25)
- Показывается только если gloryShards > 0

**Тип карты (верх-право):**
- Glass-бейдж: background rgba с backdrop-filter: blur(6px)
- Lucide-иконка (10px) + текст названия типа (8px, weight 600)
- border-radius: 10px
- Цвет фона и текста зависит от типа (см. таблицу цветов)

## SM карта (110×160) — маркет / рука

### Структура

1. **Арт** (~57% высоты, ~82px)
   - Градиентный fade снизу
   - Поверх (absolute, верх-лево): стоимость (16×16 орб) + осколки славы (мини-бейдж, если есть)

2. **Нижняя панель** (flex: 1, ~63px)
   - **Название** — 9px, weight 700
   - **Нижняя строка** (justify-content: space-between):
     - Слева: lucide-иконка типа карты (12×12, без текста)
     - Справа: иконки способностей в мини-квадратах (16×16, border-radius: 4px)

### Иконки способностей на SM

| Способность | Lucide-иконка | Цвет фона | Цвет иконки |
|-------------|---------------|-----------|-------------|
| Мракобой (strike) | sword | rgba(69,10,10,0.6) | #fca5a5 |
| Укрытие (evade) | shield | rgba(30,27,77,0.6) | #c4b5fd |
| Тотальный мракобой (totalStrike) | crosshair | rgba(69,10,10,0.6) | #fca5a5 |
| Печать (seal) | sparkle | rgba(46,16,101,0.6) | #d8b4fe |

Отображаются только те иконки, для которых у карты есть соответствующее свойство.
`general` не отображается как иконка — оно есть у всех карт и не несёт дополнительной информации.

## Общие стили

### Фон карты
- background: rgba(13,11,31,0.92)
- Внешняя тень: box-shadow 0 8px 32px [цвет типа с alpha 0.12]
- Внутренний highlight: inset 0 1px 0 rgba(255,255,255,0.04)

### Бордер
- Толщина: 1.5px (LG), 1.5px (SM)
- border-radius: 14px (LG), 10px (SM)
- Цвет: из таблицы типов

### Типографика
- Шрифт: Inter
- Название: 15px/800, цвет #f1f5f9 (LG); 9px/700, цвет #f1f5f9 (SM). Хаос: #fca5a5
- Описание: 11px/500, line-height 1.7, цвет #cbd5e1 (LG)
- Тип: 8px/600 (LG бейдж), цвет из таблицы типов (столбец "Бейдж текст")
- SM иконка типа: цвет из таблицы типов (столбец "Бейдж текст")

### Отступы
- LG padding арта: 0 (full-bleed)
- LG padding названия: 10px 12px 6px
- LG padding описания: 10px 14px
- LG gap между строками описания: 5px
- SM padding нижней панели: 5px 7px
- SM gap между иконками способностей: 2px
- Gap стоимость ↔ осколки: 4px (LG), 3px (SM)

### Примечания
- `sparkle` (singular) — иконка печати/проклятой печати. `sparkles` (plural) — иконка типа "Искра". Это разные lucide-иконки, выбраны намеренно
- `simpleDescription` не используется в новом дизайне
- `ownerNickname` не отображается на карточке

### Хаос — особая карта
- Без стоимости (нет орба)
- Без осколков славы
- Название: цвет #fca5a5 вместо белого
- Арт: абстрактный с иконкой flame по центру (opacity 0.4)
- SM: без иконок способностей (только иконка типа flame)
