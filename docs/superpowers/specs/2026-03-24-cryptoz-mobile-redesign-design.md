# Cryptoz: мобильный редизайн

## Контекст

Текущий UI игры Cryptoz — desktop-first. На мобильных устройствах (портрет, ~375px) игра неудобна: элементы мелкие, сайдбар занимает место, карты нечитаемы, drag-and-drop не работает.

## Цели

- Удобная игра на телефоне в портретной ориентации
- Все ключевые элементы доступны без потери контекста
- Карты читаемы и тапабельны
- Единый паттерн взаимодействия

## Глоссарий

- **Осколки славы** (`gloryShards`, ★) — очки игрока, показываются в чипе игрока
- **Осколки Философского камня** (`stoneShards`, 💎) — глобальный ресурс комнаты, показываются в ресурсной панели
- **Эссенция** (`essenceToSpend`, ⚡) — валюта для покупки карт в маркете (у активного игрока)
- **Компаньон** (`companion`) — карта активного игрока (`activePlayer.companion`), покупается из маркета
- **Предвестник** (`harbinger`) — карта комнаты (`room.harbinger`), покупается из маркета. `countHarbingers` — счётчик оставшихся
- **Безумие тьмы** (`darknessMadness`) — массив карт комнаты, покупается из маркета. Показывается верхняя карта + счётчик
- **Хаос** (`activeChaos`) — хранится в store, но не рендерится в UI напрямую (обрабатывается через DialogService)
- **Ноктуллос** (`hasNoctullos`) — булевый статус игрока, отображается иконкой в чипе

## Параметры игры

- Игроков: 2–8
- Карт в маркете: 3–6
- Карт на арене: не ограничено (до 20+)
- Карт в руке: переменное количество

## Архитектура экрана (портрет, сверху вниз)

### ① Игроки (горизонтальный скролл)

- **Компактные чипы**: ник + HP (`health`, ♥) + осколки славы (`gloryShards`, ★)
- Статусные иконки: онлайн/офлайн, ноктуллос (`hasNoctullos`), корона тьмы (`hasDarknessCrown`)
- Активный игрок: пульсирующая точка + подсветка бордера
- Текущий игрок (я): выделен цветом бордера
- **Тап по чипу** → bottom sheet с деталями:
  - Полное HP, слава, кол-во карт в руке
  - Стопки: печати (`seals`), компаньон (`companion`), способности (`abilities`), сброс (`discard`), колода (`deck`), рука (`hand` — только кол-во для чужих)
  - Каждая стопка тапабельна → открывает список карт
- Скрытая информация: мини-стопки карт, статусы — только по тапу

### ② Мини-арена (тикер)

- **Одна строка**: индикатор хода + "Ход: [ник]" + мини-превью сыгранных карт (22×30px)
- Превью в горизонтальном ряду, показывают последние карты
- Стрелка-шеврон справа (>) как affordance
- **Тап** → bottom sheet с полной ареной:
  - Горизонтальный скролл карт (~70×96px)
  - Тап по карте на арене → модалка с полной картой (только просмотр)
- **Пустое состояние**: если на арене нет карт — тикер показывает только "Ход: [ник]" без превью

### ③ Ресурсная панель

Горизонтальная строка иконок между тикером арены и маркетом.

Элементы скрываются, если их значение 0 или массив пуст (аналогично десктопу: `!!roomStore.room.cursedSeal.length`).

| Элемент | Тапабельный | Действие по тапу | Скрывается при |
|---------|-------------|------------------|----------------|
| 🃏 Колода (`countDeck`) | Нет | — | `countDeck === 0` |
| 🔮 Проклятые печати (`cursedSeal`) | Да | Модалка со всеми печатями | `cursedSeal.length === 0` |
| 💀 Удалённые карты (`removed.cards`) | Да | Модалка со списком всех удалённых | `removed.cards.length === 0` |
| 🌀 Удалённые хаосы (`removed.chaos`) | Да | Модалка со списком всех удалённых хаосов | `removed.chaos.length === 0` |
| 💎 Осколки камня (`stoneShards`) | Да | Модалка с осколками философского камня | `stoneShards.length === 0` |
| 👑 Корона тьмы | Нет | Визуальный индикатор (свободна / у кого) | Никогда (всегда видна) |
| — разделитель — | | | |
| 📜 Логи | Да | Drawer снизу (80% экрана), badge непрочитанных | Никогда |
| 💬 Чат | Да | Drawer снизу (80% экрана), badge непрочитанных | Никогда |

### ④ Маркет (основная зона)

- Занимает основную часть экрана (`flex: 1`, `overflow-y: auto`)
- **Заголовок**: "Маркет" + badge эссенции (⚡ N)
- **Специальные карты** — отдельная строка сверху (горизонтальный ряд):
  - **Компаньон** (`activePlayer.companion`): показывается если есть. Тап → модалка + "Купить". Скрывается когда `null`
  - **Предвестник** (`room.harbinger`): показывается если есть + счётчик `countHarbingers`. Тап → модалка + "Купить". Скрывается когда `null`
  - **Безумие тьмы** (`room.darknessMadness`): показывается верхняя карта + счётчик `darknessMadness.length`. Тап → модалка + "Купить". Скрывается когда массив пуст
- **Карты маркета** (`room.market`): CSS Grid `grid-template-columns: repeat(3, 1fr)`, `gap: 8px`
  - Карты ~100px шириной, aspect-ratio 2/3
  - Показано: арт-превью + название + цена (⚡)
  - Доступные карты (цена ≤ `essenceToSpend`): зелёный бордер + badge "Доступна"
  - Недоступные: серый бордер
- **5+ карт**: вертикальный скролл внутри зоны маркета (2 ряда = 6 карт)
- **Тап по карте** → модалка:
  - Полная карта (200px шириной): название, арт, описание, характеристики
  - Кнопка "Купить (⚡N)" (зелёная, активна если хватает эссенции и `!isInteractionLocked`)
  - Кнопка закрытия (✕)
- **Пустой маркет**: текст "Маркет пуст" в центре зоны

### ⑤ Рука + действия (fixed внизу)

- **Заголовок**: "Рука (N)" + кнопки действий
- **Карты**: горизонтальный ряд, ~52×72px, по центру
  - При большом кол-ве карт: уменьшаются или перекрываются (как на десктопе)
- **Тап по карте** → модалка:
  - Полная карта с описанием
  - Кнопка "Сыграть" (индиго) — только когда мой ход и `!isInteractionLocked`
  - Кнопка закрытия (✕)
- **Кнопки** (видны только когда `isMeActive && isGameStarted && !isGameEnded`):
  - "Все ▶▶" — разыгрывает все карты из руки (см. раздел ниже)
  - "Конец хода" — вызывает `socketService.endTurn()`
- **Не мой ход**: кнопки скрыты, карты по-прежнему тапабельны для просмотра (модалка без кнопки "Сыграть")
- **Пустая рука**: текст "Нет карт" в зоне руки
- **Зритель** (`countViewers`): зона руки скрыта полностью (рука `undefined` для не-игроков)

## Паттерн взаимодействия с картами

Единый паттерн для всех карт в игре:

| Контекст | Тап | Действие в модалке |
|----------|-----|--------------------|
| Карта в руке (мой ход) | Модалка с полной картой | **Сыграть** |
| Карта в руке (не мой ход) | Модалка с полной картой | Только просмотр |
| Карта в маркете | Модалка с полной картой | **Купить (⚡N)** |
| Карта на арене | Модалка с полной картой | Только просмотр |
| Карта в стопке игрока | Модалка с полной картой | Только просмотр |
| Компаньон/Предвестник/Безумие | Модалка с полной картой | **Купить** |

## Новая функция: "Разыграть все"

- Кнопка "Все ▶▶" в панели руки
- Отправляет серверу команду на последовательный розыгрыш всех карт из руки
- **Порядок**: слева направо (в порядке массива `hand`)
- **Карты с выбором цели**: если карта требует выбор участника (модалка выбора), процесс приостанавливается — сервер отправит модалку выбора через DialogService, игрок выбирает, после чего розыгрыш продолжается
- **Карты с условиями**: если карта не может быть сыграна — пропускается (серверная валидация)
- Видна только когда ход текущего игрока
- **Реализация**: новый метод `socketService.playAllCards()` → серверный обработчик

## Адаптивность

- Дизайн применяется на viewport `< 640px` (Tailwind `sm` breakpoint)
- На `>= 640px` остаётся текущий десктопный layout
- Переключение через существующий хук `useDeviceWidth` (`isSm = false` при `< 640px`)
- Drag-and-drop отключается на мобильном — заменяется тап-модалкой
- Существующий `DrawerPopover` уже переключается на Drawer при `!isSm` — используем его для логов/чата без изменений

## Модалки и overlays

### Типы

- **Модалка карты** (user-initiated): центрирована, backdrop затемнение, кнопка ✕
- **Bottom sheet** (user-initiated): арена, детали игрока — выезжает снизу, ~60-80% экрана, swipe down для закрытия
- **Drawer** (user-initiated): логи, чат — существующий `DrawerPopover`, 80% экрана
- **Серверная модалка** (server-initiated): диалоги выбора (SelectVariant, SuggestEvade и т.д.) — управляются через `DialogService`/`DialogProvider`

### Приоритетность

- Серверные модалки имеют приоритет над пользовательскими
- Если открыта пользовательская модалка карты и приходит серверный диалог — пользовательская закрывается, серверная открывается
- Bottom sheet может оставаться открытым при появлении модалки (разные слои z-index)
- Максимум одновременно: 1 bottom sheet + 1 модалка (как текущий DialogProvider: 1 активная + 1 свёрнутая)

## Не затрагивается этим редизайном

- `activeChaos` — не рендерится в UI, обрабатывается через DialogService
- `pendingAckNicknames` — не рендерится в UI напрямую
- Состояния загрузки/disconnect — существующее поведение (redirect на страницу игры при disconnect)
- Анимации — повторяют существующие паттерны (Framer Motion spring для карт, AnimatePresence для появления/исчезновения)
