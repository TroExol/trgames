# Инструкции для репозитория
- Пользовательские настройки клиента хранятся в `client/src/stores/SettingsStore/SettingsStore.ts` и должны синхронно сохраняться в `localStorage` при изменении значений.
- Экспортируйте экземпляры глобальных хранилищ из `client/src/stores/index.ts`, чтобы использовать единую точку входа `@/stores`.
- Настройки следует группировать по областям (например, `general`, `cryptoz`) внутри хранилища, чтобы не пересекались параметры разных игр.
