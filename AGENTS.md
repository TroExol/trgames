# Инструкции для репозитория
- Пользовательские настройки клиента хранятся в `client/src/stores/settings/SettingsStore.ts` и должны синхронно сохраняться в `localStorage` при изменении значений.
- Экспортируйте экземпляры глобальных хранилищ из `client/src/stores/index.ts`, чтобы использовать единую точку входа `@/stores`.
- Для клиентских настроек разделяйте общие и игровые параметры по соответствующим разделам стора.
