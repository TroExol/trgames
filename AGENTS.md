# Инструкции для агентов

- Репозиторий организован как монорепозиторий. Для тестов серверной части используйте команду `yarn workspace @trgames/server test`.
- В серверной игре Cryptoz хаос-карты считаются системными: если вы изменяете логику работы с ними, убедитесь, что они остаются только в `room.deck` или `room.removed.chaos` и не попадают в зоны участников.
- Пользовательские настройки клиента хранятся в `client/src/stores/SettingsStore.ts` и должны синхронно сохраняться в `localStorage` при изменении значений.
- Для клиентских настроек разделяйте общие и игровые параметры по соответствующим разделам стора.
- Соблюдайте текущий стиль TypeScript и предпочтительные паттерны проекта (стрелочные функции, использование утилит и групп карт).
- Для диалогов в Cryptoz поддерживайте логику, что одновременно может существовать только одна активная и одна свернутая модалка; используйте `DialogService` и `DialogStore` для управления этим поведением.
